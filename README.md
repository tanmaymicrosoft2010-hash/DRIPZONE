# DRIPZONE 
DRIPZONE
The ultimate destination for modern streetwear. This is the official repository for the DRIPZONE web application.
What is DRIPZONE?
DRIPZONE is a high-energy e-commerce storefront designed for speed and style. Built to showcase premium apparel, this project focuses on a "mobile-first" shopping experience with a clean, minimalist aesthetic that lets the products do the talking.
 Tech I Used
Frontend: HTML5, CSS3 (Custom animations), and Vanilla JavaScript.
Backend: firebase 
Deployment: Hosted on Netlify for lightning-fast load times.

Design: Focused on high-contrast visuals and responsive layouts.
